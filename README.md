# Segway Robotics at the AI Center

**A Barry University AI Center project exploring autonomous robotics, AI integration, and human–robot interaction.**

[View the project page](https://rocks06.github.io/Segway-Robotics-Robot-in-AI-Center/)

## Overview

This project documents early work with a Segway Robotics platform in the AI Center. The initiative explores how a mobile robot can be programmed, connected to intelligent services, and used as a practical environment for robotics and AI experimentation.

Areas of exploration include:

- autonomous movement and navigation;
- perception and environmental awareness;
- integration with AI models and services;
- natural human–robot interaction;
- research, demonstrations, and student learning.

## Repository

The repository contains the static microsite created to introduce the project and its goals.

```text
index.html   Single-page robot project microsite
```

## Context

Developed as part of work at the AI Center at Barry University. This repository presents the project concept and public-facing microsite; it does not contain the robot's complete control system or proprietary platform software.
